## Screen 4 — Exercise 2: Complete the diary

**Tip:** Multiple Choice
**Zadatak:** "Finish each diary line."

1. ___ je kiša. *(stranica s današnjim datumom, oblak)* → **Danas** / Sutra / Tjedan
2. ___ je vikend! *(stranica subote)* → Jučer / **Sutra** / Dan
3. Jučer je bila* torta. → *(prikazano kao gotova fraza uz sličicu — bez izbora, samo audio)*
4. ___ je dobar dan. *(sunce, današnja stranica)* → **Danas** / Jučer / Vikend

**Interno:** r. 3 je pasivna izloženost perfektu (*je bila*) — samo audio kartica, ne vježba. Može se i izbaciti ako rušimo konzistentnost.
