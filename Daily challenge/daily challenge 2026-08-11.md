## Screen 1 — Hook

Remember the gender trick from the beach? 🌊 Today it pays off.

Adjectives in Croatian *dress to match* their noun: **crven** auto, **crvena** kuća, **crveno** sunce. Same word, three outfits. Walk through town and color everything you see.

---

## Screen 2 — The pattern

**Tip:** Card Showcase + mini-objašnjenje

The adjective copies the noun's ending:

- auto je **crven** (M — suglasnik)
- kuća je **crvena** (Ž — -a)
- sunce je **crveno** (S — -o)

**Kartice (audio):** crven/crvena/crveno · plav/plava/plavo · velik/velika/veliko

## Screen 3 — Exercise 1: Color the town

**Tip:** Multiple Choice (slika + rečenica s prazninom)
**Zadatak (na ekranu):** "Pick the right form — the adjective has to match!"

1. Auto je ___. *(plavi auto)* → **plav** / plava / plavo
2. Kuća je ___. *(velika kuća)* → velik / **velika** / veliko
3. More je ___. → plav / plava / **plavo**
4. Jabuka je ___. → crven / **crvena** / crveno
5. Brod je ___. → **velik** / velika / veliko
6. Sunce je ___. → velik / velika / **veliko**

**Pravilo svladavanja:** svih 6 točno; pogrešne se vraćaju s novom imenicom istog roda.
