## Screen 4 — Exercise 2: How is everyone?

**Tip:** Multiple Choice (slika osobe + rečenica — recikla roda iz DC5)
**Zadatak:** "Look at each person and pick the right sentence. Watch the ending — *he* and *she* feel differently!"

1. *(muškarac zijeva)* → **On je umoran.** / On je umorna. / Ona je umoran.
2. *(žena sa sendvičem, sretna)* → Ona je gladan. / **Ona je gladna.** / On je gladna.
3. *(dijete plače)* → On je sretan. / **On je tužan.** / On je žedan.
4. *(žena s praznom čašom)* → **Ona je žedna.** / Ona je žedan. / Ona je ljuta? — distraktor s upitnikom, humor
5. *Kako si?* → ✅ **Dobro sam!** / Dobro si! / Račun, molim.

**Pravilo svladavanja:** sve točno; kombinacije se miješaju.
