# Verb Twins: Aspect
cjelina: Lesson 19

## The deepest secret
format: tekst
- Here's Croatian's deepest secret, saved for near the end: almost every verb has a *twin*.
- *Pisati* = to be writing. ***Na**pisati* = to get it written. *Piti* = to be drinking. ***Po**piti* = to drink it up.
- One twin describes the *doing*, the other the *getting done*. English needs whole phrases for this — Croatian does it with a prefix. Once you see it, you'll see it everywhere.

## When to use which
format: tekst
- **Process twin** — duration, repetition, background: *Pisao sam pismo **cijelo poslijepodne**. Svaki dan **pijem** kavu.*
- **Done twin** — completion, result, single event: ***Napisao sam** pismo! **Popio je** kavu **odmah**.*
- The tell-tale words: *cijeli dan / dugo / svaki dan* → process. *Napokon / odmah / za dvije minute* → done.

- Čitala sam knjigu cijeli tjedan. | PROCESS

- Pio je kavu polako. | PROCESS
