Croland — mini games 🎮

Twelve working prototypes from the mini-igre.md plan. Each game is a standalone HTML file with its own vocabulary — it touches neither app.html, nor data.js, nor the slike/ and zvuk/ folders. Illustrations and pronunciation are looked up in the mini games media/ folder; while that is empty, the games run on built-in symbols.

Every game has an endless mode that unlocks once you beat it — the „Endless ▶" button on the final screen.

Scoring. Every game pays out the same amount in all four currencies (LP · VP · GP · PP). The payout is one-off — a maximum you have already collected is not paid again. The maximum stays hidden until you reach it.
Progress is saved in localStorage, separately for each game.
