## Samo se der mijenja
id: l04-05
naslov_en: Only der changes
format: tekst
info: Kad je imenica **objekt** (onaj koga ili što imaš, vidiš, voliš), stoji u akuzativu. Mijenja se samo muški rod: *der → den*, *ein → einen*. Ženski i srednji ostaju isti.
info_en: When a noun is the **object** (who or what you have, see, love), it is in the accusative. Only the masculine changes: *der → den*, *ein → einen*. Feminine and neuter stay the same.
infokratko: Objekt (**koga? što?**) je u akuzativu. Mijenja se samo muški rod: *der → **den***, *ein → **einen***.
infokratko_en: The object (**whom? what?**) is in the accusative. Only the masculine changes: *der → **den***, *ein → **einen***.
opis: Usporedi dva stupca tablice — mijenja se samo jedan redak. Zatim u prazna polja upiši pravi član.
opis_en: Compare the two columns — only one row changes. Then type the right article in the gaps.
most_hr: Isto pitanje kao u hrvatskom: *koga? što?* — „Imam **brata**.“ Razlika: u njemačkom se promjena vidi na članu, a ne na kraju imenice. I mijenja se samo muški rod.
most_en: Like *he → him*: the subject form changes when it becomes an object. In German this happens to the article, and only for masculine nouns.
- tab: | nominativ (tko? što?) // nominative (who?) | akuzativ (koga? što?) // accusative (whom?)
- tab: muški // masc. | der / ein Bruder | **den / einen** Bruder
- tab: ženski // fem. | die / eine Schwester | die / eine Schwester
- tab: srednji // neut. | das / ein Kind | das / ein Kind
- Der Bruder ist hier. Ich habe einen Bruder. | Brat je ovdje. Imam brata. // The brother is here. I have a brother.
- hr: **Sad ti.**
- en: **Your turn.**
- Ich habe [einen] Hund. | Imam psa. // I have a dog.
- Ich habe [eine] Katze. | Imam mačku. // I have a cat.
- Ich besuche [den] Opa. | Posjećujem djeda. // I'm visiting grandpa.

## kein — nemam nijednog
id: l04-08
naslov_en: kein — not a, no
format: tekst
info: *kein* niječe imenicu: *Ich habe keinen Bruder* (nemam brata). Mijenja se točno kao *ein*: *keinen, keine, kein*.
info_en: *kein* negates a noun: *Ich habe keinen Bruder* (I don't have a brother). It changes exactly like *ein*: *keinen, keine, kein*.
infokratko: **kein** niječe imenicu: *Ich habe **keinen** Hund.* Mijenja se kao *ein*. *nicht* ide uz pridjev.
infokratko_en: **kein** negates a noun: *Ich habe **keinen** Hund.* It changes like *ein*. *nicht* goes with adjectives.
opis: Ana nema sestru, Jonas nema dijete — kako se to kaže? Pogledaj tablicu, pa u prazna polja upiši *keinen*, *keine* ili *kein*.
opis_en: Anna has no sister, Jonas has no child — how do you say that? Check the table, then type *keinen*, *keine* or *kein* in the gaps.
most_hr: Hrvatski kaže „**ne**mam brata“ — negacija je na glagolu. Njemački je stavlja na imenicu: *Ich habe **keinen** Bruder.*
most_en: Like English *no*: "I have **no** brother" = *Ich habe **keinen** Bruder*. Never *nicht ein*.

- hr: *nicht* ide uz pridjev (*nicht alt*), *kein* uz imenicu (*kein Hund*).
- en: *nicht* goes with an adjective (*nicht alt*), *kein* with a noun (*kein Hund*).
