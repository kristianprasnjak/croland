## Glagoli mjesta
id: v14-04
naslov_en: Place verbs
format: kartice
info: Parovi: **stavljam** (kamo? + akuzativ) i **stoji / leži / visi** (gdje? + dativ).
info_en: Pairs: **I put** (where to? + accusative) and **it stands / lies / hangs** (where? + dative).
infokratko: Kamo? *stellen, legen, hängen*. Gdje? *stehen, liegen, hängen*. *hängen → gehängt / gehangen*.
infokratko_en: Where to? *stellen, legen, hängen*. Where? *stehen, liegen, hängen*. *hängen → gehängt / gehangen*.
opis: Glagoli-blizanci zajedno sa svojim participima. Okreći kartice i uči ih u paru.
opis_en: Twin verbs together with their participles. Flip the cards and learn them as pairs.
- stellen → hat gestellt | staviti (uspravno) // to put (upright)
- stehen → hat gestanden | stajati // to stand
- legen → hat gelegt | položiti // to lay, put (flat)
- liegen → hat gelegen | ležati // to lie
- hängen → hat gehängt | objesiti // to hang (something)
- hängen → hat gehangen | visjeti // to hang, be hanging
- stecken → hat gesteckt | utaknuti // to put into, stick
- tragen → er trägt | nositi // to carry
- putzen → hat geputzt | čistiti // to clean
- auf·räumen → hat aufgeräumt | pospremiti // to tidy up
