## Osjećaji
id: v18-01
naslov_en: Feelings
format: kartice
info: Kako se osjećaš?
info_en: How do you feel?
infokratko: Osjećaji: *glücklich ↔ traurig*, *nervös*, *einsam*, *stolz*. Strah: *Angst haben **vor***.
infokratko_en: Feelings: *glücklich ↔ traurig*, *nervös*, *einsam*, *stolz*. Fear: *Angst haben **vor***.
opis: Njemački ima riječ i za čežnju za domom: *das Heimweh* — doslovno „bol za domom“. Ana je zna napamet. Okreći kartice, slušaj i ponavljaj.
opis_en: German even has a word for homesickness: *das Heimweh* — literally "home ache". Anna knows it by heart. Flip the cards, listen and repeat.
- glücklich | sretan // happy
- traurig | tužan // sad
- froh | veseo, drag // glad
- wütend | bijesan // angry
- nervös | nervozan // nervous
- aufgeregt | uzbuđen // excited
- einsam | usamljen // lonely
- enttäuscht | razočaran // disappointed
- überrascht | iznenađen // surprised
- zufrieden | zadovoljan // satisfied
- stolz | ponosan // proud
- verliebt | zaljubljen // in love
- die Angst, Ängste | strah // fear
- Angst haben vor (+ Dat.) | bojati se // to be afraid of
- das Heimweh | čežnja za domom // homesickness

## S prijedlogom
id: v18-03
naslov_en: With a preposition
format: kartice
info: Glagol + stalni prijedlog. Svi ovdje traže akuzativ.
info_en: Verb + fixed preposition. All of these take the accusative.
infokratko: Glagol + prijedlog + akuzativ: *sich freuen **auf***, *sich interessieren **für***, *warten **auf***.
infokratko_en: Verb + preposition + accusative: *sich freuen **auf***, *sich interessieren **für***, *warten **auf***.
opis: Glagol i njegov prijedlog uči kao par. Okreći kartice, slušaj i ponavljaj.
opis_en: Learn each verb and its preposition as a pair. Flip the cards, listen and repeat.
- sich freuen auf | veseliti se (nečemu što dolazi) // to look forward to
- sich freuen über | radovati se (nečemu) // to be happy about
- sich ärgern über | ljutiti se zbog // to be annoyed about
- sich interessieren für | zanimati se za // to be interested in
- sich erinnern an | sjećati se // to remember
- sich kümmern um | brinuti se o // to look after
- warten auf | čekati // to wait for
- denken an | misliti na // to think of

## Odnosi

info: Prijatelji, ljubav i svađa.

- die Liebe | ljubav // love
- der Partner / die Partnerin | partner, partnerica // partner
- verheiratet | oženjen, udana // married
- getrennt | rastavljen // separated
- der Streit | svađa // argument
- das Missverständnis, Missverständnisse | nesporazum // misunderstanding
- vertrauen (+ Dat.) | vjerovati, imati povjerenja // to trust

- duzen / siezen | govoriti ti / Vi // to say du / Sie
- der Bekannte / die Bekannte | poznanik, poznanica // acquaintance
- allein | sam // alone

## Modali u prošlosti
id: v18-05
naslov_en: Modals in the past
format: kartice
info: Präteritum modala — bez preglasa.
info_en: The Präteritum of modals — no umlaut.
infokratko: Bez preglasa: *können → konnte*, *müssen → musste*, *dürfen → durfte*, *wollen → wollte*.
infokratko_en: No umlaut: *können → konnte*, *müssen → musste*, *dürfen → durfte*, *wollen → wollte*.
opis: Kao dijete nisi smio, smjela sve. Okreći kartice i nauči modale u prošlosti.
opis_en: As a child you weren't allowed to do everything. Flip the cards and learn the modals in the past.
- können → konnte | mogao // could
- müssen → musste | morao // had to
- wollen → wollte | htio // wanted to
- dürfen → durfte | smio // was allowed to
- früher | prije, nekad // in the past, used to
- als Kind | kao dijete // as a child

info: Spoji situaciju i osjećaj.

- Ich habe eine Party für dich gemacht! | überrascht
