## Dva para glagola
id: g14-02
naslov_en: Two verb pairs
format: tekst
info: *stellen / legen / hängen* = radnja, kretanje → akuzativ. *stehen / liegen / hängen* = stanje → dativ.
info_en: *stellen / legen / hängen* = action, movement → accusative. *stehen / liegen / hängen* = state → dative.
infokratko: Radnja: *Ich **stelle** die Flasche in **den** Kühlschrank.* Stanje: *Sie **steht** im Kühlschrank.*
infokratko_en: Action: *Ich **stelle** die Flasche in **den** Kühlschrank.* State: *Sie **steht** im Kühlschrank.*
opis: Tri para glagola i njihovi participi. Samo čitaj i slušaj — ovdje se ne boduje.
opis_en: Three verb pairs and their participles. Just read and listen — nothing is scored here.
most_hr: Kao *staviti* i *stajati*: *Stavljam bocu u hladnjak* (kamo?) → *Boca stoji u hladnjaku* (gdje?).
most_en: Like *put* and *be*: "I put the bottle into the fridge" → "The bottle is in the fridge". German says *stands* for upright things and *lies* for flat ones.
- tab: radnja (Wohin? + Akk.) // action | stanje (Wo? + Dat.) // state
- tab: Ich **stelle** die Flasche in den Kühlschrank. | Die Flasche **steht** im Kühlschrank.
- tab: Ich **lege** das Buch auf den Tisch. | Das Buch **liegt** auf dem Tisch.
- tab: Ich **hänge** die Jacke an die Tür. | Die Jacke **hängt** an der Tür.
- hr: Uspravno (boca, ormar, čaša) → *stellen / stehen*. Položeno (knjiga, mobitel, tepih) → *legen / liegen*.
- en: Upright (bottle, wardrobe, glass) → *stellen / stehen*. Flat (book, phone, carpet) → *legen / liegen*.
- hr: Perfekt: *hat gestellt, hat gestanden, hat gelegt, hat gelegen, hat gehängt* (objesio), *hat gehangen* (visjelo).
- en: Perfect: *hat gestellt, hat gestanden, hat gelegt, hat gelegen, hat gehängt* (hung up), *hat gehangen* (was hanging).

## Zamke
id: g14-07
naslov_en: Common traps
format: izbor
info: Česte greške: *stehen* s akuzativom, *stellen* s dativom, zaboravljeni *ins / im*.
info_en: Common mistakes: *stehen* with the accusative, *stellen* with the dative, forgotten *ins / im*.
infokratko: *stellen* + akuzativ, *stehen* + dativ; *ins Bad gehen*; *gehängt* (objesio) ≠ *gehangen* (visjelo).
infokratko_en: *stellen* + accusative, *stehen* + dative; *ins Bad gehen*; *gehängt* (hung up) ≠ *gehangen* (was hanging).
opis: Tri rečenice, samo jedna točna. Dodirni je — i ne daj da te blizanci zbune.
