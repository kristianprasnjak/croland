## Zanimanja
id: v07-01
naslov_en: Jobs
format: kartice
info: Zanimanja u paru. *der Student, der Polizist, der Kollege, der Kunde* imaju posebne oblike (*den Studenten*) — za sada ih koristi samo kao subjekt.
info_en: Jobs in pairs. *der Student, der Polizist, der Kollege, der Kunde* have special forms (*den Studenten*) — for now use them only as the subject.
infokratko: Zanimanja u paru: *der Arzt / die **Ä**rzt**in***, *der Lehrer / die Lehrer**in***. Ženski oblik: **-in**.
infokratko_en: Jobs in pairs: *der Arzt / die **Ä**rzt**in***, *der Lehrer / die Lehrer**in***. Female form: **-in**.
opis: Njemački dodaje *-in* i problem je riješen: *Lehrer, Lehrerin*. Ponekad uz to ide i preglas, onako za stil. Okreni karticu, poslušaj i ponovi oba oblika.
opis_en: German adds *-in* and the job's done: *Lehrer, Lehrerin*. Sometimes it throws in an umlaut too, just for style. Flip each card, listen and repeat both forms.
- der Arzt / die Ärztin | liječnik / liječnica // doctor

- der Koch / die Köchin | kuhar / kuharica // cook
- der Verkäufer / die Verkäuferin | prodavač / prodavačica // shop assistant
- der Ingenieur / die Ingenieurin | inženjer / inženjerka // engineer
- der Kellner / die Kellnerin | konobar / konobarica // waiter
- der Student / die Studentin | student / studentica // student
- der Polizist / die Polizistin | policajac / policajka // police officer
- der Mechaniker / die Mechanikerin | mehaničar / mehaničarka // mechanic
- der Pfleger / die Pflegerin | med. tehničar / med. sestra // nurse
- der Designer / die Designerin | dizajner / dizajnerica // designer
- der Chef / die Chefin | šef / šefica // boss

- der Kunde / die Kundin | kupac / kupac (ž) // customer

## Glagoli i pravila

info: Glagoli za posao i riječi za pravila.
