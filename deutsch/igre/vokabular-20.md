## Glagoli za razmišljanje
id: v20-02
naslov_en: Thinking verbs
format: kartice
info: Glagoli koji često uvode *dass, ob* ili W-pitanje.
info_en: Verbs that often introduce *dass, ob* or a W-question.
infokratko: **wissen** = činjenica (*Ich weiß, dass…*), **kennen** = osoba, mjesto (*Ich kenne Lena*).
infokratko_en: **wissen** = a fact (*Ich weiß, dass…*), **kennen** = a person or place (*Ich kenne Lena*).
opis: Znaš li ili poznaješ? Okreći kartice i nauči glagole za razmišljanje.
opis_en: Do you *know* it or *know* them? Flip the cards and learn the thinking verbs.
- wissen → er weiß | znati // to know (a fact)
- kennen → hat gekannt | poznavati // to know (a person, place)
- überlegen → hat überlegt | razmišljati // to think over
- vergessen → er vergisst | zaboraviti // to forget
- verstehen → hat verstanden | razumjeti // to understand
- erklären → hat erklärt | objasniti // to explain
- beschreiben → hat beschrieben | opisati // to describe
- bemerken → hat bemerkt | primijetiti // to notice
- zweifeln → hat gezweifelt | sumnjati // to doubt
- sicher sein | biti siguran // to be sure
- gespannt sein | biti napet, znatiželjan // to be curious, eager

## Ponavljanje: glagoli s prijedlogom
id: v20-04
naslov_en: Review: verbs with prepositions
format: razvrstavanje
info: Koji prijedlog ide uz glagol?
info_en: Which preposition goes with the verb?
infokratko: *warten **auf***, *sich interessieren **für***, *denken **an***, *sprechen **mit***.
infokratko_en: *warten **auf***, *sich interessieren **für***, *denken **an***, *sprechen **mit***.
opis: Ponavljanje iz cijelog tečaja: razvrstaj glagole po prijedlogu koji ide uz njih.
opis_en: A review of the whole course: sort the verbs by the preposition that goes with them.
stupci: AUF | FÜR | AN | MIT
- warten | AUF
- sich freuen (dolazi // coming) | AUF
- sich interessieren | FÜR
- danken (za nešto // for sth) | FÜR
- denken | AN
- sich erinnern | AN
- sprechen (s nekim // with sb) | MIT
- anfangen (s nečim // with sth) | MIT
