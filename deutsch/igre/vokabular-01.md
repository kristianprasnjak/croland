## Male riječi
id: v01-01
naslov_en: Little words
format: kartice
info: Riječi koje čuješ u svakom razgovoru. *bitte* znači i „molim“ i „izvoli“.
info_en: Words you hear in every conversation. *bitte* means both "please" and "you're welcome".
infokratko: Male riječi za svaki razgovor: *ja, nein, danke* — **bitte** = molim i izvoli.
infokratko_en: Little words for every conversation: *ja, nein, danke* — **bitte** = please and you're welcome.
opis: Dobra vijest: pola ovih riječi već si čuo, čula u lekciji — *ja*, *nein*, *danke*. Okreni karticu i ponovi naglas.
opis_en: Good news: you've already heard half of these in the lesson — *ja*, *nein*, *danke*. Flip the card and say it aloud.
- ja | da // yes
- nein | ne // no
- gut | dobar; dobro // good; well
- sehr | vrlo, jako // very
- und | i // and
- aber | ali // but
- ich | ja // I
- du | ti // you (informal)
- Sie | Vi // you (formal)
- danke | hvala // thank you
- bitte | molim; izvoli // please; you're welcome
- Entschuldigung | oprostite // excuse me

## Glagoli i upitne riječi
id: v01-02
naslov_en: Verbs and question words
format: kartice
info: Šest glagola za predstavljanje i četiri upitne riječi. Glagole učiš s oblikom za *ich*.
info_en: Six verbs for introductions and four question words. You learn the verbs with their *ich* form.
infokratko: Glagol s oblikom za *ich*: *kommen → ich komme*. Pitanja: **wer, wie, woher, wo**.
infokratko_en: Each verb with its *ich* form: *kommen → ich komme*. Questions: **wer, wie, woher, wo**.
opis: Okreni karticu, poslušaj i ponovi naglas. S ovim riječima pitaš i odgovaraš kao Ana.
opis_en: Flip the card, listen and say it aloud. With these words you ask and answer just like Anna.
- sein → ich bin | biti // to be
- heißen → ich heiße | zvati se // to be called
- kommen → ich komme | doći, dolaziti // to come
- wohnen → ich wohne | stanovati // to live
- lernen → ich lerne | učiti // to learn
- sprechen → ich spreche | govoriti // to speak
- wer | tko // who
- wie | kako // how
- woher | odakle // where from
- wo | gdje // where
- aus | iz // from
- in | u // in

## Pronađi parove
id: v01-05
naslov_en: Find the pairs
format: parovi
info: Spoji pozdrav s prijevodom.
info_en: Match each greeting with its meaning.
infokratko: *guten Morgen* = dobro jutro, *guten Abend* = dobra večer, *tschüss* = bok (na rastanku).
infokratko_en: *guten Morgen* = good morning, *guten Abend* = good evening, *tschüss* = bye.
opis: Spoji pozdrav s njegovim značenjem. Kad pogodiš par, čuješ izgovor.
opis_en: Match each greeting with its meaning. Get a pair right and you hear it spoken.
- guten Morgen | dobro jutro // good morning
- guten Tag | dobar dan // good day
- guten Abend | dobra večer // good evening
- gute Nacht | laku noć // good night
- tschüss | bok // bye
- auf Wiedersehen | doviđenja // goodbye
- danke | hvala // thank you
- Wie geht's? | Kako si? // How are you?
