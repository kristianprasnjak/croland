## ein ili eine?
id: t02-02
naslov_en: ein or eine?
format: nastavak
info: Dodaj nastavak ili ostavi bez.
info_en: Add the ending or leave it.
infokratko: Samo ženski rod dobiva **-e**: *eine Zeitung*, ali *ein Heft*, *ein Spiegel*.
infokratko_en: Only feminine nouns add **-e**: *eine Zeitung*, but *ein Heft*, *ein Spiegel*.
opis: Treba li *ein* nastavak -e? Jedan dodir po rečenici.
opis_en: Does *ein* need an -e? One tap per sentence.
nastavci: e | -
- Das ist ein___ Zeitung. | Ovo su novine. // This is a newspaper. | e
- Das ist ein___ Heft. | Ovo je bilježnica. // This is a notebook. | -
- Das ist ein___ Spiegel. | Ovo je ogledalo. // This is a mirror. | -
- Das ist ein___ Farbe. | Ovo je boja. // This is a colour. | e
- Das ist ein___ Foto. | Ovo je fotografija. // This is a photo. | -
- Das ist ein___ Tasche. | Ovo je torba. // This is a bag. | e

## Zamjenica
id: t02-03
naslov_en: Pronoun
format: izbor
info: Izaberi *er, sie* ili *es*.
info_en: Choose *er, sie* or *es*.
infokratko: *der* → **er**, *die* → **sie**, *das* → **es**: *Das Heft? Es ist gelb.*
infokratko_en: *der* → **er**, *die* → **sie**, *das* → **es**: *Das Heft? Es ist gelb.*
opis: Izaberi zamjenicu koja paše uz član.
opis_en: Pick the pronoun that matches the article.
- Der Rucksack? ___ ist schwer. | Er | Sie | Es
- Die Farbe? ___ ist schön. | Sie | Er | Es
- Das Heft? ___ ist gelb. | Es | Er | Sie
- Der Bleistift? ___ ist kurz. | Er | Es | Sie
- Die Zeitung? ___ ist alt. | Sie | Es | Er

id: t02-06
