## Svaka imenica ima partnera
id: l02-05
naslov_en: Every noun has a partner
format: tekst
info: Njemački ima tri roda: muški (*der*), ženski (*die*) i srednji (*das*). Rod riječi ne slijedi uvijek značenje, pa se član uči zajedno s imenicom.
info_en: German has three genders: masculine (*der*), feminine (*die*) and neuter (*das*). Gender doesn't always follow meaning, so the article is learned together with the noun.
infokratko: Tri roda, tri člana: **der** (*der Stuhl*), **die** (*die Tür*), **das** (*das Fenster*).
infokratko_en: Three genders, three articles: **der** (*der Stuhl*), **die** (*die Tür*), **das** (*das Fenster*).
opis: Pročitaj i poslušaj. U prazna polja upiši član.
opis_en: Read and listen. Type the article into each gap.
most_hr: I hrvatski ima tri roda — ali ga vidiš na kraju riječi (*stol, lampa, krevet*). U njemačkom rod pokazuje član ispred riječi. *der Tisch* je muški kao *stol*, ali *das Bett* je srednji, a *krevet* muški.
most_en: English has one word, *the*. German has three. Learn every noun as a pair: *der Tisch*, never just *Tisch*.
- tab: rod // gender | član // article | primjer // example
- tab: muški // masculine | der | der Tisch
- tab: ženski // feminine | die | die Lampe
- tab: srednji // neuter | das | das Bett
- hr: Imenica uvijek počinje velikim slovom — i usred rečenice.
- en: A noun always starts with a capital letter — even mid-sentence.
- hr: **Sad ti.** Napiši član.
- en: **Your turn.** Write the article.
- [der] Stuhl | stolac // chair
- [die] Tür | vrata // door
- [das] Fenster | prozor // window

## ein, eine, ein
id: l02-06
naslov_en: ein, eine, ein
format: tekst
info: Neodređeni član: *ein* za muški i srednji rod, *eine* za ženski. *Das ist ein Tisch* — „ovo je (neki) stol“.
info_en: The indefinite article: *ein* for masculine and neuter, *eine* for feminine. *Das ist ein Tisch* — "this is a table".
infokratko: **ein** za muški i srednji, **eine** za ženski: *ein Tisch*, *ein Bett*, *eine Lampe*.
infokratko_en: **ein** for masculine and neuter, **eine** for feminine: *ein Tisch*, *ein Bett*, *eine Lampe*.
opis: Pročitaj i poslušaj. U prazna polja upiši *ein* ili *eine*.
opis_en: Read and listen. Type *ein* or *eine* into each gap.
most_hr: Hrvatski nema člana, pa ti se *ein* može činiti suvišnim. U njemačkom je obavezan: *Das ist ein Tisch*, nikad *Das ist Tisch*.
most_en: Like English *a*: *a table* = *ein Tisch*. Only feminine nouns add *-e*: *eine Lampe*.
- tab: | određeni // definite | neodređeni // indefinite
- tab: muški // masc. | der Tisch | ein Tisch
- tab: ženski // fem. | die Lampe | eine Lampe
- tab: srednji // neut. | das Bett | ein Bett
- hr: Kad nešto pokazuješ prvi put: *ein/eine*. Kad o tome dalje govoriš: *der/die/das*.
- en: When you show something for the first time: *ein/eine*. When you keep talking about it: *der/die/das*.
- Das ist eine Uhr. Die Uhr ist alt. | Ovo je sat. Sat je star. // This is a clock. The clock is old.
- hr: **Sad ti.**
- en: **Your turn.**
- Das ist [eine] Tasche. | Ovo je torba. // This is a bag.
- Das ist [ein] Buch. | Ovo je knjiga. // This is a book.
- Das ist [ein] Schlüssel. | Ovo je ključ. // This is a key.

## Pridjev se ne mijenja
id: l02-08
naslov_en: The adjective stays the same
format: tekst
info: Iza *ist* pridjev se **ne mijenja**: *Der Tisch ist groß. Die Lampe ist groß. Das Bett ist groß.* Isti oblik za sva tri roda.
info_en: After *ist* the adjective **does not change**: *Der Tisch ist groß. Die Lampe ist groß. Das Bett ist groß.* Same form for all three genders.
infokratko: Iza *ist* pridjev se **ne mijenja**: *Der Tisch ist groß. Die Lampe ist groß.* **nicht** ide ispred.
infokratko_en: After *ist* the adjective **never changes**: *Der Tisch ist groß. Die Lampe ist groß.* **nicht** goes before it.
opis: Pročitaj i poslušaj. U prazna polja upiši pridjev ili *nicht*.
opis_en: Read and listen. Type the adjective or *nicht* into each gap.
most_hr: Ovdje je njemački lakši od hrvatskog: *velik, velika, veliko* — a na njemačkom samo *groß*.
most_en: Exactly as in English: *the table is big, the lamp is big*.
- tab: | groß | neu
- tab: der Tisch | Der Tisch ist groß. | Der Tisch ist neu.
- tab: die Lampe | Die Lampe ist groß. | Die Lampe ist neu.
- tab: das Bett | Das Bett ist groß. | Das Bett ist neu.
- hr: Riječ *nicht* (ne) stoji ispred pridjeva: *Das Bett ist nicht neu.*
- en: The word *nicht* (not) goes before the adjective: *Das Bett ist nicht neu.*
- hr: **Sad ti.**
- en: **Your turn.**
- Die Uhr ist [alt]. | Sat je star. // The clock is old.
- Das Zimmer ist [klein]. | Soba je mala. // The room is small.
- Der Stuhl ist [nicht] neu. | Stolac nije nov. // The chair is not new.
