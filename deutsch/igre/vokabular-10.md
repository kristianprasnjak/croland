## Vikend
id: v10-01
naslov_en: The weekend
format: kartice
info: Glagoli za vikend s participom.
info_en: Weekend verbs with their participle.
infokratko: Glagol + particip: *feiern → gefeiert*, *grillen → gegrillt*, *backen → gebacken*.
infokratko_en: Verb + participle: *feiern → gefeiert*, *grillen → gegrillt*, *backen → gebacken*.
opis: Ovdje svaki glagol putuje sa svojim participom: *feiern → gefeiert*, *backen → gebacken*. Okreći kartice i uči ih u paru.
opis_en: Here every verb travels with its participle: *feiern → gefeiert*, *backen → gebacken*. Flip the cards and learn them as a pair.

- grillen → gegrillt | roštiljati // to barbecue
- backen → gebacken | peći // to bake
- putzen → geputzt | čistiti // to clean
- aus·schlafen → ausgeschlafen | naspavati se // to sleep in
- bügeln → gebügelt | glačati // to iron
- erzählen → erzählt | pričati // to tell
- bekommen → bekommen | dobiti // to get
- verbringen → verbracht | provesti // to spend (time)
- verstehen → verstanden | razumjeti // to understand
