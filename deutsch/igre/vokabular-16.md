## Kupovina odjeće
id: v16-03
naslov_en: Buying clothes
format: kartice
info: Glagoli i riječi za kupovinu odjeće.
info_en: Verbs and words for buying clothes.
infokratko: **passen** = veličina (*Die Hose passt*), **stehen** = izgled (*Rot steht dir*).
infokratko_en: **passen** = size (*Die Hose passt*), **stehen** = look (*Rot steht dir*).
opis: Jonas je u kabini za presvlačenje i ništa mu ne pristaje. Okreći kartice i nauči riječi za kupovinu.
opis_en: Jonas is in the changing room and nothing fits. Flip the cards and learn the shopping words.
- tragen → er trägt | nositi // to wear
- an·ziehen → hat angezogen | obući // to put on
- aus·ziehen → hat ausgezogen | skinuti // to take off
- an·probieren → hat anprobiert | isprobati // to try on
- um·tauschen → hat umgetauscht | zamijeniti // to exchange
- passen | pristajati (veličinom) // to fit
- stehen (+ Dat.) | pristajati (izgledom) // to suit
- die Größe, Größen | veličina // size
- die Umkleidekabine | kabina za presvlačenje // changing room
- das Angebot, Angebote | ponuda, akcija // special offer
- der Rabatt | popust // discount
- bequem | udoban // comfortable
- eng | uzak, tijesan // tight
- weit | širok // loose, wide
