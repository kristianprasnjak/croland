## Slavlja
id: v15-01
naslov_en: Celebrations
format: kartice
info: Rođendani, blagdani i zabave.
info_en: Birthdays, holidays and parties.
infokratko: Slavlja: *der Geburtstag, die Feier, die Hochzeit*. Blagdani bez člana: *Weihnachten, Ostern*.
infokratko_en: Celebrations: *der Geburtstag, die Feier, die Hochzeit*. Holidays without an article: *Weihnachten, Ostern*.
opis: Njemački kalendar ima *Weihnachten, Ostern, Silvester* — i barem jedan rođendan s tortom svaki tjedan. Okreći kartice, slušaj i ponavljaj.
opis_en: The German calendar has *Weihnachten, Ostern, Silvester* — and at least one birthday with cake every week. Flip the cards, listen and repeat.
- der Geburtstag, Geburtstage | rođendan // birthday
- die Feier, Feiern | proslava // celebration
- die Party, Partys | zabava, tulum // party
- feiern → hat gefeiert | slaviti // to celebrate
- die Hochzeit, Hochzeiten | vjenčanje // wedding
- das Fest, Feste | slavlje, blagdan // festival, celebration
- Weihnachten | Božić // Christmas
- Ostern | Uskrs // Easter
- Silvester | Stara godina // New Year's Eve
- Neujahr | Nova godina // New Year's Day
- der Feiertag, Feiertage | praznik // public holiday
- der Gast, Gäste | gost // guest
- ein·laden → er lädt ein | pozvati // to invite
- die Einladung, Einladungen | pozivnica // invitation
- die Kerze, Kerzen | svijeća // candle

## Darovi
id: v15-02
naslov_en: Gifts
format: kartice
info: Glagoli darivanja — svi mogu imati dativ (komu?) i akuzativ (što?).
info_en: Giving verbs — they can all take a dative (to whom?) and an accusative (what?).
infokratko: Komu što: *schenken, geben, schicken, zeigen, bringen*. *Ich schenke **ihr** **ein** Geschenk.*
infokratko_en: Who gets what: *schenken, geben, schicken, zeigen, bringen*. *Ich schenke **ihr** **ein** Geschenk.*
opis: Što ćeš pokloniti baki Hildi? Okreći kartice i nauči glagole darivanja.
opis_en: What will you give Oma Hilde? Flip the cards and learn the verbs of giving.
- das Geschenk, Geschenke | poklon // present
- schenken → hat geschenkt | pokloniti // to give (as a present)
- geben → er gibt | dati // to give
- schicken → hat geschickt | poslati // to send
- zeigen → hat gezeigt | pokazati // to show
- bringen → hat gebracht | donijeti // to bring
- leihen → hat geliehen | posuditi (nekomu) // to lend
- erzählen → hat erzählt | pričati // to tell
- erklären → hat erklärt | objasniti // to explain
- wünschen → hat gewünscht | željeti (nekomu) // to wish
- die Karte, Karten | čestitka; karta // card
- der Blumenstrauß, Blumensträuße | buket // bouquet
- die Torte, Torten | torta // gateau, cake
- das Paket, Pakete | paket // parcel

## Glagoli s dativom
id: v15-03
naslov_en: Verbs with the dative
format: kartice
info: Ovi glagoli uvijek traže dativ: *Ich helfe **dir**.*
info_en: These verbs always take the dative: *Ich helfe **dir**.*
infokratko: Uvijek dativ: *helfen, danken, gefallen, schmecken, gehören, gratulieren*. *Ich helfe **dir**.*
infokratko_en: Always dative: *helfen, danken, gefallen, schmecken, gehören, gratulieren*. *Ich helfe **dir**.*
opis: Ovi glagoli ne mogu bez dativa. Okreći kartice, slušaj i ponavljaj.
opis_en: These verbs can't live without the dative. Flip the cards, listen and repeat.
- helfen → er hilft | pomoći // to help
- danken → hat gedankt | zahvaliti // to thank
- gefallen → es gefällt | sviđati se // to please, like
- schmecken → hat geschmeckt | biti ukusan // to taste (good)
- gehören → hat gehört | pripadati // to belong to
- passen → hat gepasst | odgovarati; pristajati // to suit; to fit
- gratulieren → hat gratuliert | čestitati // to congratulate
- antworten → hat geantwortet | odgovoriti // to answer
- glauben → hat geglaubt | vjerovati (nekomu) // to believe (someone)
- wehtun → es tut weh | boljeti // to hurt

## Redni brojevi
id: v15-04
naslov_en: Ordinal numbers
format: kartice
info: Redni brojevi za datume: *am ersten, am zweiten…*
info_en: Ordinal numbers for dates: *am ersten, am zweiten…*
infokratko: Redni brojevi: *-te* do 19, *-ste* od 20. Nepravilni: *erste, dritte, siebte, achte*.
infokratko_en: Ordinals: *-te* up to 19, *-ste* from 20. Irregular: *erste, dritte, siebte, achte*.
opis: Kojeg je datuma zabava? Okreći kartice i nauči redne brojeve.
opis_en: What date is the party? Flip the cards and learn the ordinal numbers.
- der erste (1.) | prvi // first
- der zweite (2.) | drugi // second
- der dritte (3.) | treći // third
- der vierte (4.) | četvrti // fourth
- der fünfte (5.) | peti // fifth
- der siebte (7.) | sedmi // seventh
- der achte (8.) | osmi // eighth
- der zehnte (10.) | deseti // tenth
- der zwanzigste (20.) | dvadeseti // twentieth
- das Datum, Daten | datum // date
