## Glagoli putovanja
id: v11-02
naslov_en: Travel verbs
format: kartice
info: Glagoli s pomoćnim glagolom u perfektu.
info_en: Verbs with their Perfekt helper verb.
infokratko: Kartica nosi i pomoćni glagol: *um·steigen → ist umgestiegen*.
infokratko_en: The card shows the helper verb too: *um·steigen → ist umgestiegen*.
opis: U Nürnbergu se presjeda! Okreći kartice i uči svaki glagol s njegovim perfektom.
opis_en: Change trains in Nuremberg! Flip the cards and learn each verb with its Perfekt.
- um·steigen → ist umgestiegen | presjesti // to change
- ein·steigen → ist eingestiegen | ući (u vozilo) // to get on
- aus·steigen → ist ausgestiegen | izaći (iz vozila) // to get off
- packen → hat gepackt | pakirati // to pack
- buchen → hat gebucht | rezervirati // to book
- übernachten → hat übernachtet | prenoćiti // to stay overnight
- besichtigen → hat besichtigt | razgledati // to visit (sights)
- wandern → ist gewandert | planinariti // to hike
- landen → ist gelandet | sletjeti // to land
- verpassen → hat verpasst | propustiti // to miss

## Vrijeme
id: v11-03
naslov_en: Weather
format: kartice
info: Vremenske prilike. *es regnet* (pada kiša), *es schneit* (pada snijeg) — uvijek s *es*.
info_en: Weather. *es regnet* (it's raining), *es schneit* (it's snowing) — always with *es*.

- der Regen | kiša // rain
- der Schnee | snijeg // snow
- der Wind | vjetar // wind
- die Wolke, Wolken | oblak // cloud
- sonnig | sunčano // sunny

- schneien → es schneit | padati (snijeg) // to snow
- windig | vjetrovito // windy

- das Grad | stupanj // degree

- Es ist bewölkt. | Oblačno je. // It's cloudy. | Sunčano je. // It's sunny. | Vjetrovito je. // It's windy.
- Es ist windig. | Vjetrovito je. // It's windy. | Sunčano je. // It's sunny. | Pada kiša. // It's raining.
