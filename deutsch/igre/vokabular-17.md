## Nepravilna usporedba
id: v17-04
naslov_en: Irregular comparison
format: kartice
info: Ove oblike treba naučiti napamet.
info_en: These forms need to be learnt by heart.
infokratko: Napamet: *gut → besser*, *viel → mehr*, *gern → lieber*, *hoch → höher*, *nah → näher*.
infokratko_en: By heart: *gut → besser*, *viel → mehr*, *gern → lieber*, *hoch → höher*, *nah → näher*.
opis: Ovi pridjevi ne slušaju pravila. Okreći kartice i ponavljaj sva tri oblika naglas.
opis_en: These adjectives don't follow the rules. Flip the cards and say all three forms aloud.
- gut → besser → am besten | dobar → bolji → najbolji // good → better → best
- viel → mehr → am meisten | puno → više → najviše // much → more → most
- gern → lieber → am liebsten | rado → radije → najradije // gladly → rather → most of all
- hoch → höher → am höchsten | visok → viši → najviši // high → higher → highest
- nah → näher → am nächsten | blizu → bliže → najbliže // near → nearer → nearest
- alt → älter → am ältesten | star → stariji → najstariji // old → older → oldest
- jung → jünger → am jüngsten | mlad → mlađi → najmlađi // young → younger → youngest
- dunkel → dunkler → am dunkelsten | taman → tamniji → najtamniji // dark → darker → darkest
